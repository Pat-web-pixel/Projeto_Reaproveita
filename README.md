# Projeto Reaproveita

Este repositório reúne o projeto **Projeto Reaproveita**, uma iniciativa voltada a promover a reutilização de materiais, itens e recursos de forma sustentável, prática e acessível.

## Objetivo

O objetivo do projeto é incentivar a economia circular, reduzir o desperdício e conectar pessoas, organizações e comunidades que desejam reaproveitar produtos e materiais em vez de descartá-los.

## Funcionalidades previstas

- Cadastro de itens para doação ou reutilização
- Busca e filtros por categoria, localização e disponibilidade
- Perfil de usuários e organização
- Histórico de trocas, doações e reutilização
- Organização de campanhas de conscientização e impacto ambiental

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Pat-web-pixel/Projeto_Reaproveita.git
```

2. Acesse a pasta do projeto:

```bash
cd Projeto_Reaproveita
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie a aplicação:

```bash
npm run dev
```

> Ajuste os comandos conforme a stack escolhida pelo projeto.
